# Wastewater Interceptor Analytics

## Overview
This project analyzes wastewater interceptor flow data to assess system capacity, rainfall impact, and future risk.  
The analysis simulates real-world infrastructure and public works analytics.

## Tools
- Python (pandas, numpy)
- Excel
- Tableau

## Project Structure
- `data/raw`: Original, unmodified datasets
- `data/processed`: Cleaned and analysis-ready data
- `notebooks`: Jupyter notebooks for each analysis phase
- `excel`: Stakeholder-ready Excel deliverables
- `tableau`: Tableau workbooks and exports
